# Authentication Issues

## AUTH-001 - Database connection failed

### Problem

The application cannot establish a connection to the database.

### Solution

1. Check whether the database server is running.
2. Verify the database server address and port.
3. Check network connectivity between the application and database server.
4. Verify the database username and password.
5. Check whether the application has permission to access the database.

## AUTH-002 - Invalid username or password

### Problem

The application rejects the provided username or password.

### Solution

1. Verify that the username is correct.
2. Verify that the password is correct.
3. Check whether the account is active.
4. Reset the password if necessary.
